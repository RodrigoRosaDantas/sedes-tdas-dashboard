## Regra para fases futuras

Todo componente reutilizado deve registrar, antes da adaptação:

1. caminho de origem;
2. commit ou versão de origem;
3. hash do arquivo de origem;
4. dependências diretas;
5. licença ou condição de uso identificada;
6. alterações efetuadas no destino;
7. testes que comprovem equivalência funcional.
