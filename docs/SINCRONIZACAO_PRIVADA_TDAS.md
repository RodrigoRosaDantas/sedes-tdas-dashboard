# Sincronização remota TDAS — desativada

O TDAS não utiliza banco de dados ou armazenamento remoto nesta versão.

- O Notion permanece como fonte oficial de planejamento e conteúdo.
- O progresso de execução permanece no armazenamento local do navegador.
- Backup e restauração locais continuam disponíveis.
- Nenhuma integração com banco de dados de outro projeto deve ser usada pelo TDAS.

Uma futura sincronização entre dispositivos só poderá ser habilitada após existir uma infraestrutura dedicada ao TDAS e autorização explícita para esse uso.
